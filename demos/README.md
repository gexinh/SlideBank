# Preloaded public slide

This bundle makes the evidence viewer usable immediately: it opens the first
sample without uploading files. It includes one TCGA-OL-A66P slide's existing
SlideBank evidence, 67 derived PNG images, and all 356 retrieval records for that
slide. The browser tree references 64 images; three additional QC/mask images
are retained because the retrieval metadata references them.

The captions and signal observations are the original precomputed bank output.
They are not regenerated by the hosted question-answering model and are not
ground-truth annotations. The original whole-slide image is available from the
source below; it is not included in this bundle.

## Source and terms

The tissue imagery comes from the TCGA Research Network, NCI. The selected
source is an **open-access Slide Image** in **TCGA-BRCA**, GDC file
`5898b4df-56ee-4ae5-8dba-faf255ec5270`; its original filename is recorded in
`manifest.json` as `slide_id`. See the [GDC file record](https://portal.gdc.cancer.gov/files/5898b4df-56ee-4ae5-8dba-faf255ec5270)
and [public file metadata](https://api.gdc.cancer.gov/files/5898b4df-56ee-4ae5-8dba-faf255ec5270).

Follow the [TCGA attribution guidance](https://www.cancer.gov/ccg/research/genome-sequencing/tcga/using-tcga-data/citing)
and [GDC data analysis policies](https://gdc.cancer.gov/analyze-data/data-analysis-policies),
including their prohibition on attempting participant re-identification. The
image data retain the source's terms; the repository's software license does
not replace those terms.

## Layout and manifest contract

```text
demos/
  manifest.json
  ui_tree/tcga-ol-a66p.ui_tree.json
  artifacts/tcga-ol-a66p/{thumb,debug,tiles,patches}/...
  bank/wsi_vqa_eval_memory_fallback.json
  bank/wsi_vqa_eval_memory_fallback.json.shards/{index.json,tcga-ol-a66p.jsonl}
```

`manifest.json` uses `slidebank-demo-manifest-v1`. `default_demo` identifies the
sample selected at startup; clients can use the first `samples` entry as a
fallback. Each entry has `id`, `label`, `slide_id`, `tree`, `images`, `row_count`,
`record_levels`, `questions`, and public `source` information. `tree` and every
`images` entry are relative to the manifest directory. `images` is the exact
allowlist for the static viewer, including the three retrieval-only QC images.
`files` records generated-file byte sizes and SHA-256 checksums.

Image references inside the UI tree are relative to its JSON file. Image
references in retrieval records, including nested JSON strings, are relative
to `demos/bank/`. The tree's `_agent` points to `../bank` and `../artifacts`;
the normal UI-tree loader resolves these paths against the tree's directory.
No source machine paths are retained.

The bank retains the original per-slide records: 14 global, 18 evidence,
54 view, 252 signal, and 18 region records. The regular
`open_memory_bank("demos/bank")` reader can use it directly. To resolve image
paths from bank metadata outside the UI, join each relative path to that bank
directory. The hosted application uses the resolved tree image paths for QA.

## Validate or synchronize an existing bundle

These operations need no original source tree, WSI files, model, or API:

```bash
python scripts/prepare_demo.py --check
python scripts/prepare_demo.py --sync-web project/demos
python -m unittest discover -s tests -p 'test_demo_bundle.py' -v
```

Static synchronization copies only `manifest.json`, the listed UI trees, and
their allowlisted PNGs. It does not copy the retrieval bank. It removes stale
files only when listed by the destination's previous demo manifest, and leaves
unrelated files and directories in place. Unsafe manifest paths and symlinks
that escape the destination are rejected.

## Rebuild from the original records

For an intentional refresh, prepare a new staging directory. The packaging
tool copies existing per-slide records and derived images; it never runs
inference and never copies an entire multi-slide bank.

```bash
python scripts/prepare_demo.py \
  --tree /path/to/source/TCGA-OL-A66P.ui_tree.json \
  --bank-dir /path/to/source/persistent_bank \
  --artifact-dir /path/to/source/artifacts/selected_slide \
  --out-dir /path/to/new/staging/demos
```

The source bank must have its indexed per-slide JSONL shards. All referenced
images must be PNGs inside the specified slide artifact directory. An existing
output manifest is never silently overwritten. Review the resulting manifest
and run validation before replacing the checked-in bundle.
