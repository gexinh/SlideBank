FROM EXPLORATION TO REUSE

A memory of what the slide shows.

Explore once. Retain observations and their supporting views. Retrieve relevant evidence when a new question arrives.

Return to the evidence

Related questions can access the same slide-specific bank instead of restarting exploration.

How to open your evidence

Export with python scripts/export_ui_tree.py --bank-dir outputs/memory_bank, then open one of the generated *.ui_tree.json files. To display images, select the local artifact folder containing the referenced PNG/JPEG files. Duplicate basenames are matched by their folder suffix; unresolved images are shown as missing. Server paths in the JSON are never fetched.

This browser provides evidence inspection. Building a bank and asking model-backed questions use the Python workbench below.
